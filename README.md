# Mi Región: Cauca 🌿

## Descripción del proyecto

Este proyecto consiste en la creación de una página web sobre mi linda región del Cauca, utilizando HTML5 y CSS3. La idea es mostrar un poco de la riqueza cultural, los paisajes naturales, los lugares turísticos y la gastronomía que hacen especial a nuestro departamento.

Con esta página quiero dar a conocer algunos de los sitios más representativos del Cauca, como el Parque Natural Puracé y Popayán, conocida como la Ciudad Blanca. También quiero destacar la comida típica de la región, especialmente las empanadas de pipián.

## Tecnologías utilizadas

- **HTML5:** lo utilicé para organizar el contenido de la página, crear las secciones, el menú de navegación, las tarjetas informativas y el pie de página.
- **CSS3:** lo utilicé para darle estilo a la página, cambiar los colores, organizar las tarjetas, ajustar las imágenes y mejorar la presentación visual.
- **Visual Studio Code:** es el editor que utilicé para escribir y organizar el código.

## Contenido de la página

La página está dividida en varias partes para que los visitantes puedan conocer mejor nuestra región:

- **Inicio:** presenta el departamento del Cauca y una pequeña introducción sobre su riqueza cultural y natural.
- **Turismo:** muestra tres tarjetas con información sobre el Parque Natural Puracé, Popayán y la gastronomía caucana.
- **Gastronomía:** destaca algunos sabores tradicionales y la importancia de conservar las recetas típicas.
- **Datos curiosos:** contiene información interesante sobre el departamento y un enlace para conocer más.
- **Pie de página:** incluye los datos del aprendiz y enlaces a redes sociales.

## Diseño y estilos

Para el diseño utilicé el color verde como uno de los principales, porque representa la naturaleza y los paisajes de nuestra región. También agregué detalles amarillos para resaltar algunos elementos.

En el archivo CSS trabajé con diferentes selectores, colores en formatos HEX, RGB, RGBA y HSL, además de márgenes, bordes, sombras, espacios internos y efectos al pasar el cursor sobre los enlaces y botones.

También utilicé Flexbox para organizar el menú y las tarjetas, y agregué una adaptación para pantallas pequeñas para que la página se pueda visualizar mejor en celulares.

## Objetivo del proyecto

Mi objetivo con este trabajo es poner en práctica los conocimientos aprendidos sobre HTML5 y CSS3, creando una página web organizada, atractiva y fácil de navegar. Además, quiero mostrar algunas de las características más importantes del departamento del Cauca y valorar su cultura, naturaleza y tradiciones.
