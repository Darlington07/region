
# Mi Región: Cauca

## Descripción del proyecto

Esta página web presenta el departamento del Cauca, Colombia.
Incluye información sobre sus lugares turísticos, su gastronomía
y algunas de sus tradiciones culturales.

El proyecto utiliza HTML5 semántico y CSS3 para organizar
y diseñar el contenido de la página.

## Tecnologías utilizadas

- HTML5
- CSS3
- Visual Studio Code
- Navegador web

## Estructura del proyecto

- index.html: estructura de la página.
- css/style.css: estilos visuales.
- img/: imágenes utilizadas en el proyecto.

## Respuestas a las preguntas de reflexión

### Punto 1. ¿Qué diferencia hay entre section y div?
¿Por qué ayuda la semántica a la accesibilidad y al SEO?

La etiqueta section se utiliza para agrupar contenido relacionado
que tiene un tema específico, normalmente con un encabezado.
La etiqueta div es un contenedor genérico que sirve para agrupar
elementos sin indicar un significado semántico específico.

La semántica ayuda a la accesibilidad porque facilita que las
tecnologías de asistencia comprendan la estructura de la página.
También puede ayudar al posicionamiento SEO porque permite a los
buscadores comprender mejor la organización del contenido.

### Punto 2. Si una regla p tiene color black y la clase
.destacado tiene color red, ¿qué color toma el párrafo y por qué?

El párrafo toma el color rojo porque el selector de clase
.destacado tiene mayor especificidad que el selector de etiqueta p.

### Punto 3. ¿Por qué la ruta de la imagen en HTML es
img/logo.png y en CSS es ../img/el-municipio-se-puede.jpg?

En HTML, la ruta img/logo.png se interpreta desde la ubicación
del archivo index.html.

En CSS, la ruta ../img/el-municipio-se-puede.jpg sube un nivel
desde la carpeta css y después entra a la carpeta img, donde está
la imagen de fondo.

### Punto 4. Sin box-sizing: border-box, ¿cuánto mide en total
una caja con width: 200px, padding: 20px y border: 5px?

El ancho total es de 250 píxeles.

Cálculo:
200 px de contenido + 40 px de padding + 10 px de bordes
= 250 px.

Se suman 20 px de padding a cada lado y 5 px de borde
a cada lado.
